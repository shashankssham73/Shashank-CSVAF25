1   What this is

Two systems that share one engine.

The Computing Visualizer turns your machine's own telemetry into an image: 43 measured channels, a Rutt/Etra scan processor, a video feedback loop, Gray-Scott chemistry on the GPU.

The Psychedelic OS points the same machinery at a desktop instead of a machine map, and adds per-glyph typography, surface layout, and a botanical view of your filesystem.

Each has its own patcher page and its own saved patch, but they share the graph engine, the operator registry and the editor. An operator built for one is available in the other.

2   How a patch becomes an image

  telemetry (43 channels, SSE)
        |
   YOUR PATCH          numbers are conditioned, analysed, combined
        |
        +--> 37 named destinations     scan.amp, fb.gain, rd.mix, chain.mix ...
        +--> $shapes                   fields to draw
        +--> $color                    the colouriser
        +--> $text                     the typography stack
        +--> $layout                   the surface stack
        +--> $bot                      the tree's geometry
        |
   THE RENDERER        source raster -> scan processor and/or chemistry
                       -> feedback -> colouriser -> screen

That list is the whole contract. Everything a patch can produce is one of those six things, and the patcher's top bar shows which of them you are currently sending.

3   The four kinds of block

KindWhat it doesOutput port?
signalMakes or shapes a numberyes
geometryMakes or transforms a shape (a field)yes, square ports
modulatorDescribes a behaviour for every letter or windowno
sinkHands something to the rendererno

The one rule: signals flow left to right and must end at a sink. A chain that ends in mid-air does nothing. There are four ways to end: an Output node, a Fill or Contour, a colouriser, or any typography or layout block.

The one surprise. Typography and layout modulators apply top to bottom by where their nodes sit on the canvas, like a layer stack. Drag a node up or down to change when it runs. A Cascade delay only affects the modulators below it.
Square ports carry shapes, round ports carry numbers. The editor refuses a wire between them and tells you why.

6   The four sources

The Psychedelic view can be pointed at four things, and they do not carry the same information.

mocktreeread my screencapture
Image chain (deflection, chemistry, feedback, colour)yesyesyesyes
Shapes (SDF)yesyesyesyes
Layout & orientationyesyesyesyes
Typography (per glyph)yesyesyesno
Semantic phase sources and targets——yesno
Botanical—yes——
Capture is pixels. A captured screen has no glyphs, no words, no elements, so the typography operators have nothing to address. For letters on your real desktop use read my screen, which goes through the Accessibility API and carries structure. The browser can process pixels; only native code can process structure.

7   Recipes

Make the desktop dissolve as the machine works

cpu.busy_pct -> Scale (x0.01) -> Low pass (0.5 Hz)
             -> Remap (0.08..0.70 -> 0..0.9) -> Output [chain.mix]

At idle the desktop is crisp and usable; under load it goes through the whole image chain. That gradient is the micro-dose: the readable desktop is one end of a continuous knob, not a separate mode.

A wave that travels along every word

cpu.busy_pct -> Scale -> Low pass -> Remap (-> 2..16) -> Wave [amplitude]
Wave: phase from = index, phase scale = 0.6

Phase from is the one control worth understanding. index restarts at every word, so the wave runs along words. word makes whole words bob in sequence. line ripples down the page. entropy makes dense text move more than repetitive text.

Draw a filter

disk.tps -> Drawn kernel (FIR) -> Scope

Draw in the green box. The drawing is the impulse response: left is now, right is the past. Flat is a boxcar average, falling is an exponential smoother, a bump at the right edge is an echo. Measured: a flat drawing gives 179.9 dB between 0.05 Hz and 3 Hz.

Let memory pressure disturb the page

vm.pageouts_per_s -> Normalise (ref 900) -> Envelope (120 / 3000 ms)
                  -> Remap (-> 0..0.22) -> Scatter [amount]

Pressure, not load. Something going wrong should not look like something merely being busy.

Grow your filesystem

disk.tps -> Normalise -> Low pass -> Remap (-> 0.35..1) -> Growth [amount]
cpu.busy_pct -> ... -> Fruit / flowers [bloom]

Switch the view source to my folders as a tree. Directories are stems, subdirectories are branches, files are fruit. Thickness follows the square root of the files in a subtree — da Vinci's rule.

8   When something looks wrong

What you seeWhy
Nothing happens at allchain.mix is 0. Press I, or wire it
A flat grey washWas a bug in dense sources; the scan processor now compensates automatically. If it returns, lower scan.density
Infinite nested windowsCapturing the screen you are showing the result on. Pick a single window in the share dialog
A block does nothingIt may not be connected. Check outline: anything you built that is missing from that list is wired to nothing
An operator with no input seems deadNot necessarily — phase from: none with rate: 0 is a constant, not a zero. The outline marks these fixed
An analysis value is stuck at 0Long windows need to refill. A 40 s autocorrelation needs 40 s, and every save or live edit restarts it
Typography does nothing on a captureCorrect. Pixels have no glyphs. Use read my screen
