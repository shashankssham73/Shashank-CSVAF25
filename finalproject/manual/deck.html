Psychedelic OS

Turning the whole screen into something you can patch

100 operators · 13 presets · built this term

The idea

Your desktop already is a signal.

Every window, every line of text, every pixel of brightness is data sitting there, unused. PSYCHE mode treats it as something you can read, select and transform — the way a synthesiser treats sound.

Not a screensaver. Not a filter. A patchable instrument whose input happens to be your own computer.

Two windows

The Patcher

Where you build. Blocks on a canvas, wires between them. Nothing is typed; everything is dragged and connected.

The Render

Where you look. It shows your real screen, processed live, and updates as you drag a number — no save, no reload.

Change anything on the left and the right moves within a sixth of a second.

The whole model, in four words

READturn the screen into pieces
→
PICKchoose which pieces
→
EFFECTdo something to them
→
OUTPUTsend it to the picture

Every patch in this project is some arrangement of these four. If you understand this line, you can read any of them.

Wires have types

Number

A changing value. Load, a wave, a measurement.

Shape

A form you can move, repeat and combine before anything is drawn.

Selection

A rule for which things an effect touches.

A wire between mismatched types is refused. That is the patcher stopping you from spending an hour on a dead patch.

READ — three ways to see a screen

Read elements
Asks macOS what is actually on screen — every button, label and line of text, with its real position and the words it contains.
Read grid
Chops the screen into equal tiles, like graph paper laid over it, and measures the brightness, colour and busyness of each one.
Read regions
Finds patches of the screen that look alike and groups them into blobs, so a toolbar comes back as one shape rather than forty tiles.

Elements need the Accessibility API and know what a word is. Grid and regions need only pixels, and work on anything.

“The filenames in Finder, but not the sidebar.” “Only the busy parts.” “Everything inside this circle.” Each of those is one or two blocks.

The psychedelic part.

OUTPUT — the only block that reaches the picture

37 destinations. Each is one dial on the renderer.

scan.ampscan.perspscan.keyscan.skewscan.gainRscan.rowStepscan.floorscan.densityfb.gainfb.zoomfb.rothero.spawnRatehero.deathProbparticle.speedtype.warpchain.mixrd.mixrd.feed

The one to remember is chain.mix.

0 = your screen, completely normal. 1 = completely transformed. Anywhere between composites the real screen back underneath — which is how the effect runs and the text stays readable.

Reading a patch: “feedback tunnel”

Ten wires. That is the entire preset.

const(1) →chain.mix
const(0.991) →fb.gain
const(58) →scan.amp
const(0.09) →scan.key
const(0.45) →scan.persp
const(0.05) →scan.density
lfo(0.019Hz) →remap
remap →fb.rot
lfo(0.009Hz) →remap
remap →fb.zoom

The grammar — three sentences

Constant → Output A dial you set and leave. Most of a preset is this.
LFO → Remap → Output A dial that moves by itself. The Remap translates −1…1 into the range that dial actually wants.
Read → Pick → Effect Cut the screen up, choose some pieces, move them.

Every one of the 13 presets is built from these three and nothing else.

Building one, from empty

  1. empty — clear the canvas
  2. Click Constant and Output in the sidebar. Wire them. Set the Output's destination to chain.mix, the Constant to 0.55. Half your screen shows through.
  3. Add LFO → Remap → Output. Remap out 8…70, destination scan.amp. Now it breathes.
  4. Add Gradient ramp. No wires — placing it is enough. Colour.
  5. save preset. Name it. It is in the list.

Eight blocks, four wires, about three minutes.

Selecting what an effect touches

An effect with nothing wired to its selection input hits everything.

Wire a Pick block into it and it hits only what that rule describes. One selection can feed several effects; two selections can be combined before they reach any.

Click something in the inspect panel and the patcher writes that element's path into a Pick block for you.

Each effect shows a live count — 64/663 — of how many things it is actually reaching. Red when it reaches nothing, which is the failure that otherwise looks identical to working.

A preset is just the patch, saved

{ "name": "feedback tunnel",
  "note": "Each frame drawn on top of the last…",
  "graph": {
    "nodes": [ { "id":"a1", "type":"const", "x":60, "y":60, "p":{ "v":1 } } ],
    "edges": [ { "from":"a1", "fo":0, "to":"a2", "ti":0 } ]
  } }

A node is a block and its settings. An edge is a wire: from this block's output, into that block's input.

No code, no special format. Anything you can build, you can save; anything saved, you can open and take apart.

Two rules that bite

One Output per destination Two blocks writing the same dial fight, and whichever runs last silently wins. This made one preset render pure white.
Match the range fb.zoom lives between 0.999 and 1.006. Feeding it a raw 0…1 wave sends it to the moon. That is what the Remap is for.

Where it stands

Working

100 operators · 13 presets · reads the live screen through the Accessibility API and as pixels · effects scoped to a chosen window · everything patchable while it runs.

Not yet

The effect runs in a window showing a processed copy of your screen. Altering the actual desktop needs a native always-on-top overlay with ScreenCaptureKit — designed, not built.
