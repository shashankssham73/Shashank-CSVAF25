## Final project — Psychedelic OS

**→ [finalproject/](finalproject/)**

Two systems sharing one patching environment.

**Psychedelic OS** turns the desktop into something you can patch. The screen
is read as structure (through the macOS Accessibility API, so it knows what a
word *is*) or as pixels, parts of it are selected by rule, and typography,
layout and image-chain effects are applied to what was selected — the way a
modular synthesiser treats sound, with the machine's own display as the
source.

**Computing Visualizer** is the other direction: machine telemetry —
processor load, memory pressure, disk and network traffic — rendered as an
image.

100 operators · 13 presets · macOS · no dependencies.
